□ 1. Seguimientos (CRUD)
└ Crear seguimiento
  POST http://localhost:3000/api/v1/watches [201 Created, 686B, 373ms]
  √  Responde 201
  √  Guarda el id
  √  Trae Location

└ Crear repetido → 409
  POST http://localhost:3000/api/v1/watches [409 Conflict, 242B, 28ms]
  √  Responde 409
  √  codigo ya_seguido

└ Crear con datos inválidos → 400
  POST http://localhost:3000/api/v1/watches [400 Bad Request, 614B, 9ms]
  √  Responde 400
  √  Detalla los campos

  GET http://localhost:3000/api/v1/watches?limit=10 [200 OK, 661B, 15ms]
